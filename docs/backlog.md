# Бэклог (известные ограничения v1)

- Viewport на Float: на документах ~2000 страниц при масштабе ×6 возможно дрожание 1–2 px в конце ленты и потеря очень медленного перетаскивания (аудит). Лечится переводом прокрутки на Double.
- Значок заметки (/Text) на страницах с поворотом 90/270° в MuPDF/Acrobat может отображаться повёрнутым (в Android/Chrome — прямо).
- Ластик удаляет только пометки текущего сеанса; ранее сохранённые пометки не стираются.
- Выделение текста и маркер по тексту — в пределах одной страницы.
- При теме «Как в системе» смена ночного режима системы не перекрашивает уже открытый документ.
- Нет onTrimMemory для кэша страниц.

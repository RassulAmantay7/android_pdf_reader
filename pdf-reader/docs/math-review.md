# Заключение physics-math-reviewer (эталон геометрии)

Вердикт: эталон подготовлен; формулы поворотов сверены численно с исходником pdfium (16 точек, CropBox ≠ MediaBox).

## Формулы
- C = норм(CropBox) ∩ норм(MediaBox); нет CropBox → MediaBox; нет MediaBox → [0 0 612 792] (pdfium). Наследование MediaBox/CropBox/Rotate по /Parent (ISO 32000-1 Table 30).
- rot = ((trunc(R)/90) rem 4), < 0 → +4. Видимый размер: rot 0/180 → W=w_c, H=h_c; 90/270 → W=h_c, H=w_c.
- Страница (x, y; Y вниз) → PDF: 0: (l+x, t−y); 90: (l+y, b+x); 180: (r−x, b+y); 270: (r−y, t−x).
- QuadPoints «Z» по осям PDF: [xmin ymax xmax ymax xmin ymin xmax ymin] (pdfium RectFromQuadPointsArray). /Rect ⊇ всех точек, округление наружу (иначе pdf.js отбрасывает).
- AP Ink/Highlight: в пространстве PDF, BBox = Rect, Matrix = I. AP /Text: BBox [0 0 20 20], Matrix [cosθ sinθ −sinθ cosθ 0 0].
- Лента: s_i = (W−2m)/w_i·z; T_{i+1} = T_i + h_i·s_i + g. Щипок — метод якоря. Ограничение прокрутки: C ≤ V → (C−V)/2, иначе clamp(0, C−V). Книга: s = min((W−2m)/w, (H−2m)/h)·z.
- Ночь (а): c′ = c + 255 − 2Y, Y по Rec.709 (= invert + hue-rotate 180°, W3C Filter Effects).
  [0.574,-1.430,-0.144,0,255, -0.426,-0.430,-0.144,0,255, -0.426,-1.430,0.856,0,255, 0,0,0,1,0]
- Толщина: w_pt = w_px / s.

## Ловушки
П1 getWidth()/getHeight() — int (писатель берёт границы из PDF). П2 наследование. П3 вывернутый/выходящий CropBox. П4 /UserUnit игнорировать в обоих местах. П5 Rect ⊇ QuadPoints. П6 порядок квадрилатерала на повёрнутых страницах. П7 /Text на повёрнутой странице. П8 дрейф щипка при фиксированных полях. П9 ночной фильтр и на слой пометок. П10 eraseColor(WHITE) до render(). П13 Ink Rect ± w/2 при круглых концах.

# PDF Ридер

Личный PDF-ридер для Android 15+: без рекламы, без доступа к интернету, без сторонних библиотек.

**Умеет:** лента и «книжное» листание, масштаб щипком, ночной режим, поиск по тексту (в т.ч. кириллица), оглавление, закладки, выделение и копирование текста, пометки (перо, маркер, заметки — сохраняются в PDF стандартными аннотациями, их видят другие программы), заполнение PDF-форм, сохранение с выбором «перезаписать / копия» и резервной копией.

## Как получить APK (сборка в GitHub Actions)

APK собирается в облаке GitHub — компьютер с Android Studio не нужен.

1. Создайте на github.com новый репозиторий (можно приватный), например `pdf-reader`.
2. Загрузите в него содержимое этой папки **кроме** папки `signing-key-НЕ-ПУБЛИКОВАТЬ` (её не загружать никогда!). Проще всего: на странице репозитория «Add file → Upload files», перетащить файлы и папки, «Commit changes».
   Папка `.github` должна оказаться в корне репозитория — без неё сборка не запустится. Если браузер не показывает скрытые папки, загрузите файл `.github/workflows/build.yml` через «Add file → Create new file», вписав путь `.github/workflows/build.yml` и вставив содержимое.
3. Добавьте ключ подписи: репозиторий → **Settings → Secrets and variables → Actions → New repository secret**. Четыре секрета — значения в файле `signing-key-НЕ-ПУБЛИКОВАТЬ/README-КЛЮЧ.txt`.
   Без ключа APK тоже соберётся, но каждое обновление придётся ставить, удалив старую версию.
4. Вкладка **Actions** → «Build APK» → дождитесь зелёной галочки (≈5–8 минут). Если сборка запустилась до добавления секретов — «Run workflow», чтобы пересобрать.
5. Вкладка **Releases** (справа на главной странице репозитория) → «Последняя сборка» → `PdfReader.apk`. Откройте эту страницу прямо на телефоне и скачайте файл.

## Установка на телефон

1. Откройте скачанный `PdfReader.apk`.
2. Android спросит разрешение устанавливать приложения из этого источника (браузер / «Файлы») — разрешите.
3. Нажмите «Установить». Play Защита может показать предупреждение о неизвестном разработчике — выберите «Всё равно установить» (приложение собрано вами).
4. Чтобы PDF открывались этим приложением по умолчанию: откройте любой PDF → «Открыть с помощью» → «PDF Ридер» → «Всегда».

**Проверка разработчиков Android.** Google вводит обязательную проверку разработчиков для приложений не из магазина (в части стран — с осени 2026, везде — в 2027). Если установка будет заблокирована: (а) бесплатный аккаунт разработчика для личного распространения (до 20 устройств), (б) «расширенная» установка с задержкой 24 ч в настройках, (в) установка через `adb install PdfReader.apk` с компьютера.

## Для разработчика

- `:core` — чистый Kotlin/JVM: разбор PDF, оглавление, инкрементальная запись пометок, геометрия просмотра, ночная цветовая матрица. Покрыт тестами (JUnit 4).
- `:app` — Android (API 35), классические View, интерфейс строится в коде.
- Версии: Gradle 8.11.1, AGP 8.7.3, Kotlin 2.0.21, JDK 17, compileSdk/minSdk/targetSdk 35.
- Сборка локально (при наличии Android SDK): `gradle :core:test :app:assembleRelease`.
- Документы: `docs/requirements.md` (ТЗ), `docs/plan.md` (план), `docs/contracts.md` (контракты модулей), `docs/design.md` (дизайн), `docs/math-review.md` (эталон формул).
